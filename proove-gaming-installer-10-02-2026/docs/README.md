# docs

Project documentation, all in English (see the documentation rules in `CLAUDE.md`).

| Path | What is there |
|------|---------------|
| `CONTEXT.md` | The glossary: a one-line definition of every project and domain term. Add to it whenever a new term appears. |
| `plans/` | One folder per change (`plans/<slug>/<slug>-plan.md`). A plan is the standing description of how its feature works, and ends with its review journal. |
| `audits/` | Dated audit reports (performance, memory, API needs, incidents). |
| `knowledge-base/` | English versions of external or translated documentation (vendor specs, protocol notes). |
| `mouse/`, `headset/` | Per-device protocol references and findings. |
| `support/` | Support and diagnosis guides, with their scripts. |
| `api/` | Backend (Launcher) API reference. |

The remaining files at this level are older device protocol notes and vendor datasheets.
