# Knowledge base

English-language reference material that supports this project, versioned with the repo
(see the **Documentation rules** section in `CLAUDE.md`).

Two kinds of documents belong here:

1. **Translations.** Any documentation that arrives in a language other than English is
   translated into English and stored here. Keep the original next to it (or note where it
   lives) so the translation can be re-checked. Example sources already in the repo that
   should be translated on first use: the Chinese vendor protocol docs under `docs/`
   (`软件驱动协议-*.xlsx`, `ry-yc3123-机械轴__*.doc`).
2. **Fetched docs.** Any documentation Claude pulls from the internet (vendor specs,
   protocol references, articles) — save the relevant English version here instead of
   re-fetching it each time.

Name files in kebab-case with a short source hint, e.g. `x43-driver-protocol-en.md`.
