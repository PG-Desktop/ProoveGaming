.Profile structure summary:

      Key matrix (index table) structure:
      There are at most 16 keys in gaming keyboard or mouse. Every key has corresponding 4-byte space
      that stores the key mode and the mapping data to the Host. Profile has an index table that records the
      function definition for each key. The firmware needs to read out the function definition of each key,
      and to parse by corresponding key mode. Then send out the right data sequence to the Host.

The format of the key index table is shown as below:

       Byte34th          Byte23rd                     Byte12nd                 Byte01st
                                                             --                       --
         Null (00H)          --
                                                         Code#1                   Code#0
    KeyBoard(01H)        Code#2                              --                    Code

There are several key modes for the 4th byte of index table, as follow:

1. Keyboard key :
   For Keyboard key, the Key mode =01H, the 1st ,The 2nd and the 3rd byte indicate the keyboard key USB
   output key code (Please refer to attached table for keyboard key).

2. Mouse Button:
   For Mouse Button, the mode = 02H, the 1st byte indicate the button key USB output key code (Please
   refer to attached table for button key)

3. Multi-media key:
   For Multi-media key, the Key mode = 03H, the multi-key key code is stored in the 1st byte and the 2nd
   byte respectively (Please refer to attached table for Multi-key).

4. ACPI key:
   For ACPI key, the Key mode = 04H, the 1st byte indicate the ACPI key USB output keycode (Please
   refer to attached table for ACPI key)

5. Macro key :
   For Macro key, the key mode =05H, the 3rd byte represent macro key type, the2nd byte represent the
   index of the macro key. There is a table of index for all macro keys. The firmware will look up the
   corresponding macro key codes from the macro key definition buffer.

6. LED Control:
   For LED settings key, the Key mode = 0AH,fucnctions define as follows table:

3rd Byte         1st byte                Function
   00             03H                 
                 

7. DPI switch key :
   For DPI switch key, the key mode = 0BH, fucnctions define as follows table:

1st byte                   Function
 01H                          DPI+
 02H                          DPI-
 03H
                           DPI+ loop

There are long M * (2 + P*2) bytes buffer for all macro keys definitions. Every macro key has maxi. P key

actions (P*2 bytes) and two bytes for repeat time. The macro buffer locate after the index buffer in the

Flash. Every Macro key define as follow:.

a. Ability to define delay in milliseconds between keys' press-and-release

b. Example: Key "A" is defined as "Shift+W" 150 millisecond delay "Release W" 100 millisecond delay

"Release Shift"

c. The mapping data is shown below:

Macro:

          Byte1                 Byte2

      Repeat Low byte      Repeat High byte

where : This provide a range of values from 1 to 65535 repeat number.

      Byte3        Byte4   Byte5             Byte6  ....   Byte2*n Byte2*n+1

      Attribute1 Code No.1 Attribute2 Code No.2     ....   Attribute n Code No.n
