PROOVE GAMING CONTROL CENTER



Official software for configuring compatible Proove Gaming devices.


With the Proove Gaming Control Center app, you can configure:
1. Keyboards:
- RGB lighting;
- buttons and keys;
- device profiles;
- other available parameters of general devices.
2. Mouse:
- RGB lighting;
- buttons;
- sensitivity of the mouse;
- device profiles;
- other available parameters of general devices.
3. Headphones:
- thickness;
- microphone;
- other available parameters of general devices.


INSTALLATION

1. Extract the ZIP archive to any folder.
2. Run the file:

Proove_Gaming_Control_Center.exe

3. Confirm the Windows administrator prompt if it appears.
4. Follow the installer instructions.


IMPORTANT

The current version of the installer does not yet include a public Code Signing digital certificate. Because of this, Windows Defender SmartScreen may display an unknown publisher warning. If you downloaded the archive from the official Proove Gaming website, this warning alone does not mean the file is malicious. Do not download or run Proove Gaming Control Center from third-party or unknown sources.
